      EXPERIMENT SETTINGS
      選擇代理與連接方式
      實驗設定
      預設每次請求開始至少相隔 6 秒，約每分鐘 10 次；不是帳號配額保證。可設 0–120 秒，0 表示停用固定間隔。畫面播放速度不影響此設定；詞元與每日配額仍可能受限。
      正式專案也能使用這種網頁介面
      網頁負責任務操作、呈現與紀錄；電腦端服務負責 AI、相機、通訊與控制。這份單檔先把虛擬設備放在瀏覽器中。
      模型 API 連線
      設定後按「套用並從零開始」。決策格式可修正 2 次；HTTP 429 可冷卻後重試 2 次，超過等待上限則停止。
      環境金鑰如何使用？
      下載原始碼，在解壓後的資料夾執行 python claude_bridge.py --key-env ANTHROPIC_API_KEY，再以橋接位址開啟介面。金鑰不會送回瀏覽器。
      V6.3 的驗證範圍
      • 首次辨識、連線、產生與驗證通訊驅動。
      • 左下起點、較遠的 A/B，逐回合改變位置。
      • 同設備每回合確認通訊，沿用驅動。
      • B 高度為 0 / 0.35 / 0.65；安全升起高度為 1。
      高度是模擬相對值：下降至當地支撐面，尚未學習未知 Z 軸或完整 3D 控制。3D 視角顯示模擬狀態；判斷由相機與工具證據取得。
