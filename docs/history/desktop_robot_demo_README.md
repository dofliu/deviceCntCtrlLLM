# 桌面機器人視覺自動控制｜概念動畫 v1

2026-10-09 · DofLab / Jui-Hung Liu

## 開啟方式

- `desktop_robot_vision_demo.html`：以 Chrome 或 Edge 開啟。全部程式內嵌，可離線使用；需瀏覽器支援 WebGL。
- `desktop_robot_vision_demo.mp4`：72 秒，1920×1080、30 fps、無聲，呈現完整正常搬運流程。
- `desktop_robot_vision_retry.mp4`：43 秒，1920×1080、30 fps、無聲，從第一次接近開始，呈現空夾、重新對位、再次夾取與放置。

## 互動版操作

拖曳旋轉、滾輪縮放；可選全景、俯視、夾爪特寫。下方可暫停、重播、拖曳時間軸、跳章節及調整播放速度。點選「空夾後重試」會跳至第 29 秒，播放失敗恢復分支。

## 分鏡

| 秒數 | 正常流程 |
|---|---|
| 0–7 | 相機觀察桌面、辨識夾爪、積木、A 與 B |
| 7–23 | 小幅往返探索，累積動作與影像位移樣本 |
| 23–29 | 建立局部映射，準備接近 |
| 29–38 | 視覺閉迴圈接近 |
| 38–46 | 下降、閉合夾爪 |
| 46–55 | 抬升驗證、搬運 |
| 55–62 | 下降、張開夾爪、放置 |
| 62–68 | 退離並確認物件留在 B |
| 68–72 | 完成 |

重試情境於 42–46 秒展示空夾驗證，46–49 秒重新對位，49–55 秒再次夾取，55–68 秒完成搬運及放置。

## 示範範圍

這是預先編排的概念動畫，不是實機操作錄影或已完成的自主控制系統。它沒有連接相機、機器人或語言模型。3D 手臂使用固定連桿長度的逆運動學重建動畫姿態；學習流程、辨識框、探索樣本數、影像偏差曲線及決策文字均為示意，不能用於宣稱真實定位精度、成功率或收斂速度。

原型假設：事先提供控制介面與安全限制；固定桌面及物件尺寸；下降高度與夾取姿態受限制。實際系統仍需處理相機遮擋、關節回授、通訊延遲、反向間隙與失敗判斷。
